# Tài liệu thực hành Lab 1 — ZAP và XSS

Làm theo thứ tự:

1. [Cài ZAP, mở EShop và cấu hình Chrome](01-cai-dat-zap-va-chrome.md).
2. [Làm Lab 1: bắt request, chạy Fuzzer và kiểm tra XSS](02-huong-dan-lab-1.md).
3. Dùng [xss-payloads.txt](xss-payloads.txt) khi hướng dẫn yêu cầu nạp payload.

Hướng dẫn dành cho **Windows + PowerShell + Chrome**. Repo đã có mã nguồn EShop trong [eshop-sut](eshop-sut), không cần tải riêng. Chỉ thực hành trên EShop localhost của môn học.

Tải cả bộ: chọn **Code → Download ZIP**, giải nén, rồi mở thư mục có file `README.md` này bằng VS Code.

Mã nguồn EShop lấy nguyên bản từ [KTPM2026/eshop-sut](https://github.com/KTPM2026/eshop-sut), nhánh `main`, commit [`4ec1e2f`](https://github.com/KTPM2026/eshop-sut/commit/4ec1e2f213011e60be7f5b0f624e200d7dc58a5c).

Biên soạn từ [hướng dẫn seminar (cần quyền truy cập)](https://github.com/KTPM2026/seminar/blob/main/docs/lab-huong-dan.md) và [tài liệu của Phát](https://github.com/KTPM2026/eshop-sut/tree/main/Phat/P1_labs).
